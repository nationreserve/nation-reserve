# Content style guide

Use plain language, sentence case, specific actions, and the participant names Robot Owner, Hiring Company, Robot Manufacturer, Nation Reserve, and RoboWorkPool. Define unavoidable acronyms. Never imply guaranteed earnings or uptime. Do not label scheduled time verified, accrued money paid, submitted payment settled, or a processing payout paid. Error copy explains what happened, whether action is required, and a safe next step.
