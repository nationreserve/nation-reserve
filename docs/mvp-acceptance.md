# MVP Acceptance Policy

`pnpm acceptance:mvp` coordinates specification validation, strict coverage, migration planning, tests, accessibility checks, critical journey checks, heartbeat simulation, source security and build. It writes JSON and Markdown under `artifacts/acceptance/`, redacts common secret forms, returns non-zero for any failed or blocked stage, and never converts missing external evidence into a pass.

A critical failure blocks release. A waiver requires elevated permission, step-up authentication, a gap, reason, risk, temporary behavior, affected organizations, expiry and follow-up issue. Financial immutability, verified-time evidence and security boundaries are not routine waiver candidates.
