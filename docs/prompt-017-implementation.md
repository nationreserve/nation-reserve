# Prompt 017 implementation

Prompt 017 implements every manufacturer route through the authenticated shell and amends Prompt 016 with company open-work-order publication, inbound interest, inbound messages, and access-request routes.

Existing application, credential, model, robot, contract, heartbeat, assignment, and reporting APIs are consumed. Discovery, service regions, outreach, expanded access, messaging, complete fulfillment projections, scheduling readiness, notification feeds, and manufacturer-specific replacement commands remain blocked pending authoritative backend contracts.

The UI preserves company-controlled disclosure, cross-manufacturer isolation, environment-separated secrets, durable serial identity, and immutable contract origin.
