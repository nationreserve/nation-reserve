# Production launch

Launch phases are internal staff, pilot manufacturers, selected owners, selected hiring companies, limited contracts, controlled availability, and general availability. Each phase defines allowlists, robot/contract/payment/payout limits, feature flags, manual settlement approval, enhanced monitoring, support ownership, reconciliation, timeline review, rollback criteria, and approval.

Production readiness is governed by [the launch checklist](checklists/production-launch.md), [manual review](checklists/prompt-021-manual-review.md), and [launch-day runbook](runbooks/launch-day.md). No phase is approved by source files alone.
