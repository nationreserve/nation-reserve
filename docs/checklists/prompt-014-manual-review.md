# Prompt 014 manual review checklist

- [ ] Registration, login, verification, reset, invitation, and logout in a real browser
- [ ] Password-manager and mobile-autofill behavior
- [ ] Account enumeration and rate-limit messages
- [ ] Locked, restricted, maintenance, and expired-session states
- [ ] Zero, one, and multiple organization first-login paths
- [ ] Organization switching and browser-back cache isolation
- [ ] Profile, password change, sessions, preferences, and notifications
- [ ] Delete-account wording and retention review
- [ ] Keyboard-only, screen-reader, high zoom, contrast, and reduced motion
- [ ] 360, 390, 768, 1024, and 1440px layouts
- [ ] Legal approval for Terms, Privacy, deletion, consent, and invitation wording
