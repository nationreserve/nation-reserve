# Post-launch validation

Controlled pilots verify registration, email, organizations, manufacturer/model/robot approval, ownership, activation, work discovery, contract/allocation/schedule, heartbeat/verified time, invoice/test-approved payment, statement/payout, notifications, audit, and timelines. Monitor registrations, robots, heartbeat rate/errors, intervals, contracts, money workflows, jobs, support, incidents, reconciliation, latency, database and timeline backlog.

The post-launch review records enabled/disabled scope, usage, failures, incidents, support, money results, heartbeat reliability, performance, accessibility/security findings, timeline completeness, feedback, fixes, and the next rollout decision.
