# Repository Evidence Audit

The machine-readable inventory at `artifacts/acceptance/repository-evidence.json` contains 607 source-controlled artifacts from applications, packages, scripts, infrastructure, workflows and documentation. Generated output, dependencies and VCS internals are excluded. Each entry records path, artifact kind, inferred domain and purpose, embedded prompt/requirement IDs, implementation-review state, test evidence, byte size and SHA-256 digest.

The inventory is an evidence index, not proof that an artifact fulfills its requirement. Fulfillment status is determined by strict specification coverage and executed acceptance stages.
