# Prompt 006 Implementation

Prompt 006 introduces robot-scoped production credentials, canonical HMAC/Ed25519
signing, immutable heartbeat evidence, replay state, status projections, bounded
verified operating intervals, downtime, offline detection, operational incidents,
company inactivity reports, review holds, fraud signals, scoped APIs, dashboards,
and a development simulator.

Payroll, payouts, invoices, payment processing, tax reporting, and the downpayment
queue remain intentionally absent. Verified operating time means evidence exists;
it does not mean money has been earned, billed, or paid.
