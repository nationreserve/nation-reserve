# Specification Management

Canonical records live in `docs/specification`. Version-controlled YAML is authoritative; PostgreSQL is only a rebuildable dashboard projection. Source precedence is approved amendment, Appendix M, Appendix A, domain appendix, functional specification, technical architecture, current prompt, then existing behavior. Conflicts are recorded rather than silently resolved.

Add requirements with a permanent `RWP-DOMAIN-NNNN` ID, primary source, testable acceptance criteria, status, and traceability. Never renumber, reuse, or delete published IDs. Superseded records remain historical.
