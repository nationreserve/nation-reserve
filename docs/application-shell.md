# Application shell

Four shells are available: public Nation Reserve, authentication, authenticated RoboWorkPool, and Platform Administration. The authenticated top bar keeps product, organization, role, search, help, notification, and user context visible. Desktop uses a sidebar; small screens use a drawer. Platform Administration adds a prominent environment indicator and permission-filtered operational navigation.

Page metadata should include a unique title, description, indexing policy, breadcrumb label, help topic, and analytics identifier. Authenticated routes must be `noindex` in deployment configuration.
