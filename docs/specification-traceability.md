# Specification Traceability

`traceability.yaml` maps requirements to prompts, packages, files, tables, APIs, screens, roles, permissions, services, jobs, configuration, events, tests, documentation, and metrics. A verified status requires actual file and test evidence. Nonapplicable dimensions must be documented rather than omitted.

Later changes to routes, migrations, permissions, calculations, states, notifications, flags, configuration, screens, or immutable behavior must update the affected mapping.
