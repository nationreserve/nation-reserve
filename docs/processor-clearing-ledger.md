# Processor clearing ledger

Collection settlement: debit `1020 Payment Processor Clearing`, credit `1000 Company Accounts Receivable`. Owner payout: debit `2000 Robot Owner Payable`, credit `1020`. Processor fees: debit `5020 Processor Fees`, credit `1020`. Chargeback funds are tracked separately in `2040 Chargeback Suspense`. Posted accrual entries are never edited.
