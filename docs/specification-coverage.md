# Specification Coverage

Coverage is reported separately for sources, requirements, immutable rules, traceability, screens, tests, APIs, permissions, explanations, security, accessibility, responsive behavior, and operations. There is intentionally no single overall percentage.

`pnpm specification:coverage` writes warning-oriented Markdown and JSON. Strict mode fails for critical current gaps. A waiver requires a reason, authorized user, affected requirement IDs, and mandatory review or expiry date.
