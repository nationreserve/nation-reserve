# Controlled Pilot Launch

Pilot access is invite-only. Configuration is versioned and persisted outside application code with limits for organizations, manufacturers, owners, robots, contracts, monthly financial volume and geography. A configuration must be separately approved before activation, and every change records reason and actor.

Recommended initial limits: one region, two manufacturers, five Hiring Companies, ten Robot Owners, twenty robots, ten concurrent contracts and a finance limit approved by Billing and counsel. These are recommendations, not active settings; an authorized operator must create and approve the production record.

Launch gates: strict specification coverage, database migration rehearsal, real browser privacy journeys, processor sandbox settlement, heartbeat staging verification, cloud security review, backup restore, incident exercise, legal publication, support staffing and signed pilot approvals.
