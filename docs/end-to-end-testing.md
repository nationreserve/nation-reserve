# End-to-end testing

Critical release journeys cover registration/MFA/recovery; owner claim, activation, earnings, statement and payout test flow; company setup, training, work order, opportunity, contract, schedule, verified time, invoice and test payment; manufacturer approval, model/robot registration, discovery, interest, allocation and heartbeat; platform approvals, incidents, reports, reconciliation and release controls.

Tests use disposable deterministic organizations and test providers. Manufacturer-initiated discovery, explicit messaging audiences, multipart upload/quarantine, duplicate/replayed heartbeat, payment timeout/webhook idempotency, Appendix O ordering/permissions, audit separation, keyboard/mobile/accessibility, and recovery paths are mandatory. Live money and production customer data are forbidden.
