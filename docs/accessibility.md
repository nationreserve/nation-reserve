# Accessibility

Target WCAG 2.2 AA. Shared shells use landmarks, meaningful headings, skip links, keyboard controls, visible focus, named dialogs, textual status, live feedback, 44px controls, reduced-motion support, and print-safe colors. Tables use captions and scoped headers. Automated structural tests are included; a full axe/browser audit and assistive-technology manual review remain required before claiming conformance.
